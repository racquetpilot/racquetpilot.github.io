ExampleMeasurements and history on one racquet

Example measurement history for a racquet strung at a 52 lb reference setting. Example data App screen

  1. Compare the stringing setting and current estimate

    The current estimate of 42.9 lb is 83% of the 52 lb reference setting, 9.1 lb lower. The setting is what was entered on the machine and the estimate comes from the stringbed's frequency, so the gap is not all change from use.

  2. Track changes since the first measurement

    Follow the changes in your measurement history, from the first reading to the latest estimate. It is not the true tension at stringing time, nor a remaining lifespan.

  3. Look back before your next setup choice

    Tension history and play log sit together on one racquet. That is your reference when deciding whether to use a setup you liked again.

No history yet? Start with your own racquet's first measurement. A racquet without a reference setting shows the change since the first reading only. Absolute tension estimates are supported first for strings we have measured directly.

How it worksHow it works

  1. 01Pick

    Your racquet and string from the list. Enter the tension and date, then start the history with an actual measurement.

  2. 02Tap

    Five taps in the middle, somewhere quiet. The mic reads the frequency. A screwdriver handle works best.

  3. 03Read

    The current estimate and measurement history on one screen. Look at tension changes alongside your play log.

EvidenceWe start by checking the data behind the math

Here is what we have checked, and what is still open.

We measure strings directly

The string data the calculation needs is measured in-house. Directly measured values and values converted from other conditions are kept apart.

We check test racquets against the physical frame

Racquet head width and length are measured with calipers and compared with dimensions derived from images. This is how we check the data used for face area.

We look at real stringing conditions

Readings are compared across racquets and stringing setups. When something is off, we look at the racquet, the string and the measurement conditions, and decide what to check next.

Is every 98 really a 98?

We lined up 23 racquets by measured face area. No. The same "98" runs from 94 to 99. So the tension math uses the measured area, not the number printed on the frame.

See how we measure area →

The tension figures in the app are estimates. The value set on the stringing machine and the value the app gives are not direct measurements of the same kind. No single number settles your ideal setup or when to restring.

FAQFrequently asked questions

What is the number the app shows?

A tension estimate calculated from the stringbed's frequency and the racquet and string data. It is not measured the same way as the value entered on a stringing machine.

It differs from my stringing setting. Is that normal?

It can. The two values are measured differently, so the gap is not all change from use. Check the reference shown on screen and follow the changes in your measurement history.

Do you record and keep the sound?

No. The taps are turned into a number on the device and are not saved as a recording. Details are in the privacy policy.

Can I use my string?

Any string in the list can be selected. Absolute tension estimates are supported first for strings we have measured directly; for the rest you follow the change since the first reading. See the string list.

Does it cost anything?

The current beta is free to join. Full-release terms will be announced with the launch information.

Can I use it for a shop or customer stringing?

Tools for shops and customer work are being developed separately. Ask about what is available now via Support.
